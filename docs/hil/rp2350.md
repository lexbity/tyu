# RP2350 HIL Evidence

Manual HIL target for the RP2350 platform pack.

Procedure:
- Flash the pack with the `uf2` deploy recipe.
- Connect UART0 at the board's debug serial port.
- Run the manual HIL target `crates/tyu/tests/platform_hil.rs::rp2350_manual_hil`.
- Capture the framed diagnostic transcript emitted over UART0.
- To validate the transcript in the repo test harness, set
  `TYU_RP2350_TRANSCRIPT=/path/to/capture.bin` and rerun the ignored hardware
  test.
- For the cross-arch mismatch demo, build the RISC-V variant with
  `crates/tyu/tests/deploy_hardware.rs::hardware_rp2350_cross_arch_abi_mismatch_demo`
  and set `TYU_RP2350_EXPECT_DIAG=1` when replaying its captured transcript.

Expected transcript shape:
- `V` record once at startup.
- `S` completion record from the test runner.
- `D` record only on traps or hard faults.

This file is the discoverable evidence anchor for the `hardware` rung. The
actual recorded transcript should be appended here after a bench run.
